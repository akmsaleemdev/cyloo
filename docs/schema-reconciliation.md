# CYLOO — Schema Reconciliation Matrix

## Executive Summary
This document provides the definitive, comprehensive reconciliation of all 111 database tables declared across migrations `0001_init.sql`, `0002_phase4.sql`, `0003_runtime_reconciliation.sql`, and `0004_zero_trust_authorization.sql` against the 85 runtime-registered entities in `apps/api/src/common/store.ts`.

- **SQL Declared Tables**: 111
- **Runtime Registered Tables**: 85
- **SQL-Only Relations**: 26 (intentionally unexposed internal/infrastructure tables)
- **Runtime Names Missing SQL Table**: 0
- **API Literals Missing SQL Table**: 0
- **Declared Tables Without Detected RLS**: 0 (100% covered by explicit RLS or restrictive deny-all)
